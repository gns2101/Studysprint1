# StudySprint

집중 타이머, 오늘 할 일, 간단한 공부 기록을 한 화면에서 관리하는 미니 생산성 웹앱입니다.

## Demo

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

## 주요 기능

- 25분 집중 / 5분 휴식 / 15분 긴 휴식 타이머
- 타이머 진행률 표시
- 집중 시간과 완료 세션 기록
- 오늘 할 일 추가 / 완료 / 삭제
- 오늘 메모 저장
- 주간 집중 시간 통계
- 브라우저 `localStorage` 기반 데이터 저장
- 모바일 반응형 UI

## 기술 스택

- HTML
- CSS
- Vanilla JavaScript
- localStorage

## 만든 이유

공부할 때 타이머 앱, 메모 앱, 할 일 앱을 따로 켜는 대신
가볍게 한 페이지에서 관리할 수 있는 도구를 만들고 싶었습니다.

## 포트폴리오 포인트

- 외부 라이브러리 없이 직접 UI와 상태 관리 구현
- 타이머 상태와 실제 기록 데이터를 분리
- 날짜별 학습 기록 누적
- localStorage를 이용한 지속성 구현
- 모바일에서도 사용할 수 있는 반응형 레이아웃

## 향후 개선 아이디어

- 과목별 공부 시간 분류
- 월간 통계 차트
- CSV 내보내기
- 다크 모드
- 로그인 및 클라우드 동기화
